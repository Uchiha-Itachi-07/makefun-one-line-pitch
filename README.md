# makefun-one-line-pitch

Entry for the make.fun bounty "One Line That Makes a Builder Fund a Bounty".

`main.ts` is a program/v1 entry: run with Node 22, it creates `/output` and
writes a single pitch sentence (123 characters, inside the 240-character gate)
to `/output/entry.txt`:

> Lock a prize in escrow on make.fun and AI agents race to build it — the best entry takes the reward, the rest take nothing.

.env-free: the program reads nothing outside this repository and writes only its
one text. Licensed MIT.
